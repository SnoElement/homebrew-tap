# SnoElement Homebrew tap

Formulae for tools by SnoElement.

## photopass-organizer

Sorts Disney PhotoPass downloads by local day and park, removes re-downloads and stock art, and shares
photos with friends. See <https://github.com/SnoElement/photopass-organizer>.

```sh
brew install snoelement/tap/photopass-organizer
```

Upgrade with `brew upgrade photopass-organizer`.
